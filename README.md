# 设备风险预警平台

这是从原项目扩展的完整源码。主要流程为：

1. 导入设备台账、运行遥测和工作维修日志。
2. 系统校验并读取最新遥测，使用当前 HistGradientBoosting 模型预测设备故障风险，并结合工况计算综合风险。
3. 智能分析页汇总风险设备、共同风险因素和建议；AI 助手可参考近期维修日志补充分析。日志是历史记录，AI 不把它当成已确认故障。
4. 在“今日报告”逐台核查，记录故障原因、处置办法、核查人。传感器数据修正只作为原值/核实值留痕，不会改写原始遥测。
5. “确认故障”和“已检查未发现故障”会反馈到已审核样本；“数据异常”和“待核实”不会被当成训练标签。
6. 在“模型训练中心”单独发起批量训练、查看评估结果，通过后由管理员发布；保留历史版本并支持回滚。

## 启动

进入 `设备风险预警平台` 目录，安装 `requirements.txt` 中的依赖，然后运行：

```bash
python dashboard.py
```

浏览器打开终端显示的本机地址（默认端口 8770）。Windows 可运行目录中的启动脚本。

## 页面

- `/`：风险概览
- `/risk`：智能分析与单设备解读
- `/devices`：设备台账、工况和工作日志
- `/report`：今日风险核查、处置报告和打印/PDF
- `/model-center`：人工反馈、候选训练、审核发布和模型回滚

## 数据与模型

设备及工作日志、模型反馈和核查报告保存在 `设备风险预警平台/data/equipment.db`。原始遥测和数据库不会被打包外的外部系统修改。新模型训练使用原始训练数据与已审核的 0/1 标签；模型评估通过后只生成待审批候选模型，需在训练中心发布后才会成为当前版本。

当前项目为单机管理员模式，未配置账号登录与多人权限认证。部署到多人或生产环境前，应接入身份认证、角色权限、备份和操作审计。
