# 风险分析与模型迭代流程

## 日常工作

设备遥测、设备台账和维修日志进入平台后，系统保留原始记录并按设备与采样时间整理数据。风险看板调用当前已发布模型预测设备本身风险，同时计算现场工况风险，输出设备排序和分级。

智能分析使用看板计算结果做规则归因和建议。AI 助手可在补充问答时参考匹配到的维修日志，但日志只代表历史记录；风险等级来自平台计算，故障根因必须由现场人员核实。

值班人员进入“今日报告”，查看风险值、采样时间和匹配到的维修日志，记录“确认故障”“已检查未发现故障”“数据有误并记录修正”或“待核实”。原始传感器值不被覆盖。报告可打印或保存为 PDF。

## 人工反馈如何进入训练

| 报告结论 | 反馈标签 | 是否参与监督训练 |
|---|---:|---|
| 确认故障 | 1 | 是 |
| 检查后未发现故障 | 0 | 是 |
| 数据修正 | 无 | 否，原始值与核实值仅留痕 |
| 待核实 | 无 | 否 |

训练在“模型训练中心”由管理员手动触发。训练程序合并原始训练集和已审核反馈，按时间划分训练集、测试集并评估候选模型。候选版本需满足自动评估条件，再经管理员审批发布；不合格的候选模型不会切换线上模型。可从历史已发布版本回滚。

## 数据解释

- 风险预测是模型对当前数据的估计，不是已经发生故障的证明。
- “已检查未发现故障”表示该采样时点经人工检查没有确认故障，不能推断设备永远无风险。
- 工作维修日志不会自动变成模型训练标签；只有报告中明确选择确认故障或检查无故障，并保存的反馈，才进入相应标签池。
- 模型训练是批量迭代，不会随着每一次分析或报告保存即时改变线上模型。
